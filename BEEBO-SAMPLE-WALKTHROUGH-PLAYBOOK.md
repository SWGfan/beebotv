# Beebo Sample Account and Product Walkthrough Playbook

**Purpose:** record a truthful product walkthrough with Beebo-owned sample media. This is a production runbook, not a claim that every planned service is live.

## Before recording

- Use a new Windows profile and the `BeeboSample` owner account only.
- Use only the dedicated Beebo sample folders and media you created or have permission to display.
- Use a temporary Wi-Fi or hotspot name with no personal information. Do not film an IP address, QR value, e-mail inbox, password, recovery code, payment detail, or real household library.
- Confirm the Windows and Android version/date shown on the download page match the installer/APK that will be recorded.
- Prepare two Android devices if recording Watch Together or guest games. A second device must use a separate sample guest identity.
- Record source clips at native resolution, then create captions and screenshots from the final capture. Product illustrations must be labelled as illustrations, never screenshots.

## Main walkthrough — 8 to 10 minutes

1. **Download and install on Windows** — begin on the Beebo Entertainment download panel, show the Windows version and release time, download, install, and open Beebo.
2. **Create the sample owner** — create or sign in to `BeeboSample`; do not show the password or recovery details.
3. **Choose media folders** — select only the Beebo sample Movie and TV folders. Explain that the owner chooses what Beebo scans.
4. **Explore the library** — open Movies and TV Shows; show poster browsing, search, a title page, and one clearly labelled missing episode/title only where it exists in the running build.
5. **Discover cast and missing-title search** — show a cast page, a title Beebo does not own, then the external-search control. If a custom search provider is configured, show that selection without implying Beebo sells or supplies the missing media.
6. **Organize** — show video playlists, the upload area, and clearing upload history. State that clearing history does not delete the original video.
7. **Connect a phone** — show the Android download panel; install the verified APK; sign in as the sample account; connect through a safe temporary QR or manual address.
8. **Phone experience** — browse Movies, TV, Continue, Downloads and Surf. Show the connection status accurately: Home, direct away connection, or relay — only the route actually used.
9. **Campsite and sharing** — with a temporary test hotspot, show Campsite Mode, a guest joining, the camp icon, and a shared Beebo-owned photo/video advancing on both phones. Never display real people’s photos without permission.
10. **Games and stories** — show the game catalogue and a small set of finished games (including `4-in-a-row` and Sea Battle), then Story Mode with neutral sample names and only the voice choices that work in the build.
11. **Watch Together** — only if fully tested on two current builds: show two sample accounts watching the same Beebo-owned sample title and demonstrate one synchronized pause/resume. Do not claim browser guest playback if it has not shipped.
12. **Close** — show account controls, privacy settings and log out. Link viewers to the exact current release/download page.

## Screenshot list for the website

Capture one approved, redacted screenshot per listed feature. The per-feature evidence, visible controls and release gate live in `PUBLIC-FEATURE-CAPTURE-CATALOGUE.md`.

- Desktop: Get Started, Movies, TV Shows, missing item, cast/title discovery, playlists, Upload, upload history, Users, privacy controls, Phone Backups, Settings and Log out.
- Android: sign-in, library, TV/missing episode, cast page, player, accurate connection route, campsite entry, guest share, story, each game category, and a representative finished game.
- Games: a genuine screenshot of every built game in its main layout. Capture bot play only where the finished game supports it; capture guest/multiplayer flow on two devices where it is the real experience.
- Website: current Windows and Android download panels, feature page navigation, game directory, legal/availability wording for external official-TV links.

## Post-production checks

- Match every public screenshot to the exact app version visible on the release page.
- Use captions for each feature’s visible action and outcome; do not add claims that are not present in the release.
- Have a second person check for private information frame by frame.
- Keep raw recordings privately; publish redacted final exports and approved WebP screenshots only.
